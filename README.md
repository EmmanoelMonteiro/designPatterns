# Design Patterns - Exemplos de Implementação

Este repositório contém exemplos práticos e simples de implementação de diversos Design Patterns (Padrões de Projeto) em JAVA. 
O objetivo é demonstrar como esses padrões podem ser aplicados para resolver problemas comuns de design de software.

## 📌 Sobre o Projeto

Design Patterns são soluções reutilizáveis para problemas recorrentes no desenvolvimento de software. Este projeto visa:

- Mostrar implementações concretas dos padrões mais utilizados
- Oferecer exemplos didáticos e bem comentados
- Facilitar o entendimento através de casos práticos

## 🛠 Padrões Implementados

### Padrões Criacionais
- [x] **Singleton** - Garante que uma classe tenha apenas uma instância
- [x] **Factory Method** - Define uma interface para criar objetos
- [x] **Abstract Factory** - Famílias de objetos relacionados
- [x] **Builder** - Separa a construção de um objeto complexo
- [ ] **Prototype** - Cria novos objetos pela clonagem

### Padrões Estruturais
- [ ] **Adapter** - Permite interfaces incompatíveis colaborarem
- [ ] **Composite** - Trata objetos individuais e compostos uniformemente
- [ ] **Decorator** - Adiciona responsabilidades dinamicamente
- [ ] **Facade** - Fornece uma interface simplificada
- [ ] **Proxy** - Controla o acesso ao objeto original

### Padrões Comportamentais
- [ ] **Observer** - Notifica mudanças a múltiplos objetos
- [x] **Strategy** - Encapsula algoritmos intercambiáveis
- [ ] **Command** - Encapsula uma solicitação como objeto
- [ ] **Iterator** - Acessa elementos de uma coleção sequencialmente
- [ ] **State** - Altera comportamento quando o estado muda
